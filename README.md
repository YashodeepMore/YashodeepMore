## 01 — AI Agent Execution & Observability Platform

<img src="./assets/projects/agent-observability.png" width="100%"/>

> **An infrastructure platform for understanding what AI agents did, why they did it, and where execution failed.**

Instead of treating an AI agent as a black box, the platform records its execution as a structured trace.

```text
User Request
     ↓
Agent Planner
     ↓
Tool Selection
     ↓
Tool Execution
     ↓
LLM Reasoning
     ↓
Final Response
     ↓
Trace + Metrics + Evaluation
```

### Key Ideas

- Agent execution tracing
- Tool-call observability
- LLM latency and token tracking
- Failure analysis
- Structured execution logs
- Evaluation pipeline
- Run comparison

## 02 — TinyStories GPT

<img src="./assets/projects/tinystories-transformer.png" width="100%"/>

> **A GPT-style decoder-only Transformer implemented from scratch in PyTorch.**

Built to understand the architecture rather than treating Transformers as a black-box library.

### Architecture

```text
Token Embeddings
      ↓
Positional Information
      ↓
Multi-Head Self Attention
      ↓
Feed Forward Network
      ↓
Residual + LayerNorm
      ↓
Repeated Transformer Blocks
      ↓
Language Modeling Head
```

### Highlights

- Decoder-only Transformer
- Multi-head self-attention
- Causal masking
- Positional embeddings
- Custom training loop
- Validation pipeline
- Model checkpointing
- TinyStories dataset

**Stack:** PyTorch • Python • HuggingFace
